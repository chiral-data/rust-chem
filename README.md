# rust-chem
Rust Implementation of Algorithms in Cheminformatics. 

[Documentation](https://docs.rs/chem)

## Implemented
- a SMILES writer `chemio/src/smiles_writer.rs`

## Inspiration
- [sdfrust](https://github.com/HFooladi/sdfrust/) — a Rust library for parsing SDF (Structure-Data File) chemistry files
- [smilesDrawer](https://github.com/reymond-group/smilesDrawer) — a lightweight JavaScript library for rendering chemical structures from SMILES, from the Reymond Group
